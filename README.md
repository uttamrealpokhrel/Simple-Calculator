# Simple Calculator

A minimal, responsive calculator built with HTML, CSS, and JavaScript.

Features:
- Basic arithmetic: +, −, ×, ÷
- Decimal support
- Percent, clear (AC), delete (backspace)
- Keyboard shortcuts (numbers, operators, Enter, Backspace, C)
- Responsive layout

How to use:
1. Open `index.html` in your browser.
2. Click buttons or use your keyboard.

To contribute:
- Add features like parentheses, exponentiation, memory, or a history view.
